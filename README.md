# Beginner Prompt Engineering Assessment

## Overview

This repository contains the deliverables for the Beginner Prompt Engineering Assessment.

The assessment demonstrates a basic prompt engineering workflow using ChatGPT, including text summarization, information extraction, formatting conversion, tone editing, and constraint-driven output.

## Completed Tasks

- ChatGPT workspace setup and navigation
- Text summarization
- Information extraction
- Formatting conversion
- Professional tone editing
- Constraint-driven output
- Prompt and raw output documentation
- Loom walkthrough
- Public GitHub repository

## Project Files

### basic_prompt_log.md

Contains the five foundational prompts, their inputs, and the raw ChatGPT outputs.

### loom_video.md

Contains the link to the Loom walkthrough video.
